# 📉 Ujjawal Trader Academy - Premium Trading Landing Page

A premium, ultra-lightweight, and mobile-first landing page designed for the **Ujjawal Trader Academy**. Built with high-performance vanilla web technologies to ensure maximum conversion and prestige.

## 🚀 Key Features

- **Prestige Design**: High-status dark mode aesthetic with emerald green and vibrant blue accents.
- **Glassmorphism UI**: Translucent cards, blurred backgrounds, and subtle glowing borders for a modern financial look.
- **Dynamic Stats Display**: Animated counters showcasing community success and win rates.
- **Video Proof Section**: Seamlessly integrated YouTube withdrawal and strategy proof.
- **Academy Curriculum**: A structured 3-module roadmap (Psychology, Price Action, Risk Management).
- **Interactive FAQ**: No-JS native HTML5 accordion for better performance and accessibility.
- **Ultra-Mobile Optimized**: Fully responsive layout from 4.5K screens down to small mobile viewports.

## 🛠️ Technology Stack

- **HTML5**: Semantic structure for SEO and accessibility.
- **CSS3**: Custom properties, Flexbox/Grid layouts, and hardware-accelerated animations.
- **Vanilla JavaScript**: Lightweight logic for animations and mobile menu toggles.
- **Lucide Icons**: Scalable vector icons for a clean visual language.

## 🌐 Live Deployment Instructions

To host this on **GitHub Pages**, follow these exact steps:

1. **Create a New Repository**: Go to GitHub and create a new public repository named `ujjawal-academy`.
2. **Open Terminal**: In your local `ujjawal` folder, run:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Professional trading site"
   ```
3. **Connect to GitHub**:
   ```bash
   git remote add origin https://github.com/YOUR_USERNAME/ujjawal-academy.git
   git branch -M main
   git push -u origin main
   ```
4. **Enable Pages**:
   - Go to your repo on GitHub.
   - Click **Settings** > **Pages**.
   - Under **Build and deployment**, set Source to **Deploy from a branch**.
   - Select `main` and `/root`. Click **Save**.

Your site will be live at `https://YOUR_USERNAME.github.io/ujjawal-academy/` in about 60 seconds! 📈🚀
